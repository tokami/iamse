# Define harvest control rule for SAM

def.hcr.sam

## Usage

``` r
def.hcr.sam(
  id = "sam",
  nonconvHCR = "conscat",
  silent = TRUE,
  verbose = FALSE,
  env = globalenv()
)
```

## Arguments

- id:

  Name/ID of HCR. Default: "sam"

- nonconvHCR:

  HCR if SAM does not converge. Default: "conscat" (constant catch).

- silent:

  silent

- verbose:

  verbose

- env:

  Environment. Default: globalenv()
