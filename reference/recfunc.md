# recfunc

Function to calculate recruitment (Beverton - Holt)

## Usage

``` r
recfunc(
  h,
  SSBPR0,
  SSB,
  R0 = 1e+06,
  method = "bevholt",
  bp = 0,
  beta = 0,
  gamma = 0,
  alpha = 0
)
```

## Arguments

- h:

  steepness

- SSBPR0:

  spawning biomass produced by one recrut in its lifetime

- SSB:

  spawning biomass

- R0:

  recruitment in unfished population

- method:

  SR type

- bp:

  breakpoint for hockey-stick SR

- beta:

  info

- gamma:

  info

- alpha:

  info
