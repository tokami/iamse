# def.hcr.ref

def.hcr.ref

## Usage

``` r
def.hcr.ref(consF = 0, fracFmsy = NULL, set. = check.set(), env = globalenv())
```

## Arguments

- consF:

  either numeric indicating constant F level or "fmsy" for fishing at
  fmsy

- fracFmsy:

  fraction of fmsy

- set.:

  settings

- env:

  environment
