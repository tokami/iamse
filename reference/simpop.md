# Simulate an age-based population

Simulate an age-based population

## Arguments

- logF:

  fishing mortality

- dat:

  List with species data

- set:

  List with MSE settings

- tvy:

  year index for all time-variant (tv) processes (so far: Msel, Ms, sel)

- opt:

  If 1 the function returns the yield in the last year, if 2 the
  function returns a list with yield, TSB, SSB, and ESB over the whole
  simulation period.
