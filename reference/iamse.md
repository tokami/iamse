# iamse: Intra-Annual Management Strategy Evaluation (IAMSE)

Provides a framework for intra-annual age-based operating models used in
management strategy evaluation (MSE) of exploited fish stocks.

## Details

The package includes tools to:

- define and simulate age-based operating models at intra-annual time
  steps,

- specify harvest control rules (HCRs) and management procedures,

- run management strategy evaluations (MSEs), and

- summarise and visualise performance metrics and trade-offs.
