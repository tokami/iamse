# getMsel

Function to estimate selectivity of natural mortality

## Usage

``` r
getMsel(
  Linf,
  K,
  mids,
  plba,
  a = 0.55,
  b = 1.61,
  c = 1.44,
  scale = TRUE,
  lunit = "cm",
  useBelow10 = FALSE
)
```

## Arguments

- Linf:

  Linf of vBGF

- K:

  K of vBGF

- mids:

  midlengths

- plba:

  probability of being in mids given age

- a:

  info

- b:

  info

- c:

  info

- scale:

  logical; scale to have maximum 1 (default: true)

- lunit:

  info

- useBelow10:

  info
